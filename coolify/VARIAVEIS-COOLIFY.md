# Variáveis do HEZZUZ Logs no Coolify

## Obrigatória

`DATABASE_URL`
: cole a URL INTERNA do PostgreSQL criado no mesmo destination do Coolify.

## Geradas automaticamente pelo Compose/Coolify

- `SERVICE_PASSWORD_ADMIN`
- `SERVICE_HEX_64_AUTHSECRET`
- `SERVICE_HEX_64_SURVIVAL`
- `SERVICE_HEX_64_LOBBY`
- `SERVICE_HEX_64_SKYBLOCK`

## Valores recomendados

```env
DATABASE_SSL=false
ADMIN_USERNAME=admin
AUTH_TOKEN_HOURS=12
EVENT_RETENTION_DAYS=90
DB_POOL_MAX=20
INGEST_MAX_BATCH=100
INGEST_RATE_PER_SECOND=500
SERVER_OFFLINE_AFTER_SECONDS=90
DISCORD_FORWARD_MODE=critical
```
